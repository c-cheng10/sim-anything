# Development logs

Internal records of how sim-anything was built and benchmarked. Users don't need these.

- `HANDOFF.md` — state, decisions, known bugs and next tasks.
- `BUDGET.md` — agent spawn log for the autonomous build.
- `AGENT_PROMPT.md` — the prompt given to blind benchmark-generation agents.
- `NEXT_SESSION.md` — the handoff prompt for the next autonomous session.
